# تقويمي – مهام: حزمة التثبيت

افتح الملف **taqwimi-install-guide.pdf**: دليل مصوّر خطوة بخطوة لرفع الملفات إلى GitHub وتثبيت التطبيق على الجوال، وبناء ملف `taqwimi.apk` اختياريًا.

## الملفات التي تُرفع إلى GitHub (ثمانية)

`index.html` · `manifest.webmanifest` · `sw.js` · `icon-192.png` · `icon-512.png` · `icon-maskable-512.png` · `make_project.py` · `build-apk.yml`

(لا يُرفع هذا الملف ولا ملف PDF.)

## ملاحظات

- على الكمبيوتر: افتح `index.html` مباشرة في Chrome أو Edge.
- بياناتك محفوظة على جهازك فقط؛ صدّر نسخة Excel احتياطية بانتظام من الإعدادات.
- لبناء APK على كمبيوتر دون GitHub: شغّل `python3 make_project.py` ثم افتح المجلد `android` في Android Studio واختر Build ← Build APK(s).
